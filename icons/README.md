# Icônes de l'extension

## 📝 Instructions

Vous devez créer **3 fichiers PNG** dans ce dossier :

- `icon16.png` (16x16 pixels) - Icône de la barre d'outils
- `icon48.png` (48x48 pixels) - Icône de gestion des extensions
- `icon128.png` (128x128 pixels) - Chrome Web Store

## 🎨 Suggestions de design

### Option 1 : Emoji converti
Utilisez un emoji 🎤 et convertissez-le en PNG aux différentes tailles.

**Outils en ligne** :
- https://emoji.gg/
- https://www.online-image-editor.com/

### Option 2 : Créer vos propres icônes

**Design recommandé** :
- Fond : Dégradé noir/gris sombre
- Symbole : Microphone blanc ou rouge
- Style : Moderne, minimaliste
- Couleur accent : Rouge (#ef4444) comme dans l'interface

**Outils recommandés** :
- Figma (gratuit)
- Canva
- Photoshop
- GIMP (gratuit)

### Option 3 : Utiliser un générateur d'icônes

- https://icon.kitchen/ (gratuit)
- https://www.favicon-generator.org/

## ⚡ Quick Start (Placeholder temporaire)

Si vous voulez tester rapidement l'extension sans créer d'icônes :

1. Créez 3 carrés de couleur unie en PNG (rouge par exemple)
2. Nommez-les `icon16.png`, `icon48.png`, `icon128.png`
3. Placez-les dans ce dossier

**Note** : Sans icônes, Chrome affichera une icône par défaut.

## 🔧 Export depuis Figma

1. Créez un carré de 128x128px
2. Dessinez votre icône
3. Exportez en PNG aux 3 tailles : 16px, 48px, 128px
